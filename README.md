# Кейс 3 - Support Copilot by Grand Mobile

Сервис триажа обращений игроков: язык, категория, приоритет, дубли и спам, факты, черновик ответа
с цитатами правил и решение «нужен человек». Работает **полностью локально, без внешних LLM API**:
стоимость 0 $ за обращение, p95 латентности около 5 мс на CPU ноутбука.

## Быстрый старт

```bash
pip install -r requirements.txt
# положить файлы кейса в data/: tickets_train.jsonl.gz, tickets_valid.jsonl, rules.json, taxonomy.json
make train                                  # ~4 минуты: слабая разметка, классификатор, база знаний
make predict IN=data/tickets_valid.jsonl OUT=out/pred.jsonl
make serve                                  # POST http://localhost:8000/triage
make eval                                   # метрики -> reports/metrics.json, примеры -> reports/examples.md
make test
make suggest                                # бонус: кандидаты в новые шаблоны по кластерам обращений
```

**Windows без make** (нужен Python 3.10+):

```powershell
py -m pip install -r requirements.txt
py scripts/train.py
py scripts/predict.py --in data/tickets_valid.jsonl --out out/pred.jsonl
py -m uvicorn app:app --port 8000      # документация и тестовые запросы: http://localhost:8000/docs
```

Если Windows блокирует DLL scikit-learn («Политика управления приложениями заблокировала этот файл»),
это Smart App Control: версия scikit-learn==1.5.2 из requirements.txt проходит проверку.

`make predict` сам обучает модели, если папки `models/` еще нет (модели не хранятся в репозитории,
потому что собраны из данных кейса).

Пример запроса:

```bash
curl -X POST localhost:8000/triage -H 'Content-Type: application/json' -d '{"kind":"complaint",
 "messages":[{"role":"player","text":"Arman_Petrov оскорблял меня и мою семью в чате, скрины есть, 2.1 ОП","attachments":2}]}'
```

Кроме `kind` и `messages` сервис принимает необязательные поля выгрузки (`server_lang`, `rule_refs_raw`,
`reported_nick`, `reporter_hash`, `reported_hash`, `created_at`, `images_count`): они уточняют язык
по умолчанию, факты и дедупликацию. Ответ строго по контракту ТЗ.

## Как устроено

```
текст игрока
  -> нормализация cp1251 (ќ->қ, є->ғ, ѕ->ң, ј->ә, ґ->ө, ў->ұ, ї->ү) и определение языка
  -> категория: правила по taxonomy.json + TF-IDF/логрегрессия, обученная на слабой разметке train
  -> приоритет: правила taxonomy.json (p0 аккаунт/платежи/угрозы вне игры, p1 читы/скам/RMT/админы, ...)
  -> факты: ник (reported_nick или из текста), существующие пункты правил, доказательства, сервер
  -> дедупликация: тот же заявитель + тот же обвиняемый (или тот же текст репорта) в течение часа
  -> черновик: шаблон ситуации на языке игрока + пункт из rules.json (RAG по правилам)
               или ответ из базы ответов админов на похожие вопросы (RAG по базе знаний)
  -> guardrails: каждая цитата проверяется по rules.json; обещания наказания, разбана, возврата
     переводят тикет в needs_human; платежи, аккаунты, жалобы на админов всегда идут человеку
```

**Почему без LLM.** Ответы админов шаблонные: вердикт + пункт + наказание. Шаблоны, собранные из
реальных ответов и подставленных пунктов правил, физически не могут выдумать пункт (20% оценки),
отвечают за миллисекунды и бесплатно (10%), а казахские и узбекские тексты написаны заранее,
а не сгенерированы маленькой моделью (15%). Модульная архитектура позволяет позже добавить LLM
только для нестандартных репортов, сохранив guardrails.

**Разметка.** Категорий и приоритетов в данных нет. Train размечен правилами: текст игрока,
поле «пункт правил» и (только при разметке) нарушение и вердикт из ответа админа. На инференсе
классификатор видит только текст игрока, ответ админа и вердикт из входа удаляются.
Для честной оценки вручную размечены 190 тикетов валидации: 120 использовались при настройке
правил, 70 размечены после и составляют отложенную выборку.

**Канонические пункты.** Номера пунктов повторяются между разделами, поэтому цитаты имеют префикс:
`2.1` общие правила (как в taxonomy.json), `ЖБ 1.2.2` правила жалоб, `GZ 1.1` Зелёная зона,
`ЛИД`, `ГОС`, `ГВ`, `СМ`, `ОПГ`, `ВЗБ`, `БЗФ` для остальных разделов.

## Метрики

| | |
|---|---|
| Точность категории (отложенная ручная разметка, 70) | 0.86 |
| macro-F1 приоритета | 0.87 |
| Цитаты, существующие в rules.json | 100% |
| Стоимость | 0 $ за обращение |
| Латентность p95 | ~5 мс |
| needs_human | 77% |

Подробно: `reports/REPORT.md` и `reports/metrics.json`.

## Бонусы

Дедупликация (тот же заявитель и обвиняемый или тот же текст в течение часа) и предложение новых
шаблонов по кластерам похожих обращений (`make suggest`, `scripts/suggest_templates.py`).

## Структура

```
app.py                 FastAPI, POST /triage
copilot/normalize.py   cp1251, язык, ники
copilot/rules.py       индекс правил, разбор ссылок игрока, BM25
copilot/labels.py      правила категорий и приоритетов, слабая разметка
copilot/classifier.py  TF-IDF + LogisticRegression, гибрид с правилами
copilot/kb.py          база ответов админов на вопросы из репортов
copilot/templates.py   шаблоны на ru/kk/uz/en/es/pt
copilot/pipeline.py    сборка ответа и guardrails
scripts/               train, predict, evaluate, eval_gold, suggest_templates
tests/                 контракт и guardrails
```

## Данные

Данные кейса в репозиторий не кладутся (`.gitignore`): условия Decentrathon запрещают их публикацию,
в том числе производных выборок. `reports/examples.md` и ручная разметка `reports/gold_*.json`
тоже не публикуются. Источники: только данные кейса, scikit-learn, FastAPI.
